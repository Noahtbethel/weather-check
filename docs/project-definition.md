# WeatherCheck — Project Definition

## 1. Purpose

Strengthen my resume by developing a full-stack application that demonstrates professional Software Development Life Cycle (SDLC) practices, Jira project management, and AI-assisted development.

## 2. Project Overview

WeatherCheck is a locally deployed weather application designed to operate independently on each installation. It allows users to search for locations, view current weather conditions and forecasts, and save locations for quick access in future sessions.

## 3. Project Objectives

- Develop a functional full-stack weather application that integrates an external weather API and persistent database storage.
- Apply professional Software Development Life Cycle (SDLC) practices, from planning and design through testing and delivery.
- Utilize Jira to organize, manage, and document the development process.
- Incorporate AI-assisted development while maintaining responsibility for technical decisions, code review, and quality assurance.
- Produce a well-documented GitHub repository that demonstrates software engineering and project management skills.

## 4. Project Scope

### In Scope
- Search for locations by name.
- Retrieve weather information from an external API.
- Display current weather conditions and short-term forecasts.
- Save, view, and remove locations using a persistent database.
- Provide a simple, responsive web interface.
- Support local deployment with documented setup instructions.

### Out of Scope
- Public hosting or cloud deployment.
- User accounts and authentication.
- Sharing saved locations between installations.
- Advanced weather analytics or custom forecasting.
- Mobile-native applications.
- Features beyond the defined project requirements.

## 5. Project Constraints

- Deployment Environment: The application must operate locally without relying on publicly hosted application infrastructure.
- Project Resources: Development will be managed by a single developer with assistance from AI programming tools.
- External Dependencies: Weather data will depend on a third-party API, including its availability, usage limits, and data coverage.
- Data Persistence: Saved locations must remain available across application restarts using local persistent storage.
- Development Process: Development must follow documented SDLC practices, with Jira used for project management and Git for version control.

## 6. Success Criteria

- Application Functionality: Users can search for locations, view current weather conditions and short-term forecasts, and save or remove locations.
- API Integration: The application successfully retrieves and displays weather information from the selected third-party API.
- Data Persistence: Saved locations remain available after the application and database are restarted.
- Testing: All defined acceptance criteria are satisfied, automated tests pass, and no known critical defects remain.
- Local Deployment: The application can be built and run locally using documented setup instructions.
- Project Management: Development activities, tasks, and milestones are tracked through Jira.
- Documentation: The GitHub repository contains complete requirements, architecture, testing, deployment, and AI-development workflow documentation.
- AI-Assisted Development: The project demonstrates documented use of AI for implementation, along with developer review and validation of its output.
