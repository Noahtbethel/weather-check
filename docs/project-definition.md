# WeatherCheck — Project Definition

## 1. Purpose

Strengthen my resume by developing a full-stack application that demonstrates professional Software Development Life Cycle (SDLC) practices, Jira project management, and AI-assisted development.

## 2. Project Overview

WeatherCheck is a full-stack web application that allows users to search for locations and view current weather conditions and short-term forecasts. The application uses a React frontend and Node.js backend to retrieve weather information from an external API. It requires no user accounts or database and will be publicly accessible through ongoing web hosting.

## 3. Project Objectives

- Develop a functional full-stack weather application that integrates an external weather API.
- Apply professional Software Development Life Cycle (SDLC) practices, from planning and design through testing and deployment.
- Utilize Jira to organize, manage, and document the development process.
- Incorporate AI-assisted development while maintaining responsibility for technical decisions, code review, and quality assurance.
- Implement continuous deployment to keep the publicly hosted application updated.
- Produce a well-documented GitHub repository demonstrating software engineering and project management skills.

## 4. Project Scope

### In Scope

- Search for locations by name.
- Retrieve weather information through the application backend.
- Display current weather conditions and short-term forecasts.
- Provide a simple, responsive web interface.
- Handle invalid searches, API failures, and unavailable weather data.
- Deploy and host the application publicly using cloud services.
- Implement continuous deployment for application updates.
- Provide documented setup and deployment instructions.

### Out of Scope

- User accounts and authentication.
- Database integration and persistent user data.
- Historical weather tracking and analytics.
- Custom weather forecasting.
- Mobile-native applications.
- Features beyond the defined project requirements.

## 5. Project Constraints

- **Deployment Environment:** The application must support local development and ongoing cloud hosting, preferably using free or low-cost services.
- **Project Resources:** Development will be led by a single developer who may delegate substantial implementation work to AI programming agents while retaining responsibility for technical decisions, code review, and quality assurance.
- **External Dependencies:** Weather information depends on a third-party API, including its availability, usage limits, and data coverage.
- **Project Complexity:** Scope will remain limited to essential functionality to prioritize timely completion.
- **Development Process:** Development must follow documented SDLC practices, using Jira for project management and Git for version control.

## 6. Success Criteria

The project will be considered complete when:

- **Application Functionality:** Users can search for locations and view current weather conditions and short-term forecasts.
- **API Integration:** The backend successfully retrieves and processes information from the selected weather API.
- **User Interface:** The application provides a functional, responsive interface.
- **Error Handling:** Invalid searches, unavailable weather data, and external API failures are handled appropriately.
- **Testing:** Defined acceptance criteria are satisfied, automated tests pass, and no known critical defects remain.
- **Deployment:** The application is publicly accessible through a stable URL, with cloud deployment and continuous deployment configured and verified.
- **Project Management:** Development activities, tasks, and milestones are tracked through Jira.
- **Documentation:** The GitHub repository contains requirements, architecture, testing, deployment, and AI-assisted development workflow documentation.
- **AI-Assisted Development:** AI-generated contributions are reviewed and validated, with the development workflow documented.
